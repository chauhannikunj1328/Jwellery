## Phase 1 – Research & product choice (start here)

Selling worldwide is the long-term goal, but **launch in 1–2 test countries
first**. Each country has its own duties, taxes, hallmarking rules and return
expectations; doing them all at once multiplies cost and risk.

### 1a. Compare product categories

Score each on 1–5 and pick the highest total. Fill this in from research.

| Factor | Gold / fine | Silver (925) | Fashion / imitation | Lab-grown diamond |
|--------|-------------|--------------|---------------------|-------------------|
| Starting capital needed (5 = low) | | | | |
| Margin potential | | | | |
| Shipping risk / insurance cost (5 = low) | | | | |
| Regulation / hallmarking burden (5 = low) | | | | |
| Return / fraud risk (5 = low) | | | | |
| Competition (5 = low) | | | | |
| Fit with our sourcing access | | | | |
| **Total** | | | | |

General trade-offs to confirm with research:
- **Gold / fine:** high value per order, but high capital, insurance, fraud
  risk and strict hallmarking rules in many countries [verify per country].
- **Silver:** mid-price, good margins, ships cheaply; hallmarking applies in
  some countries above certain weights [verify].
- **Fashion / imitation:** lowest capital and easiest to ship; very crowded,
  so brand and niche matter most.
- **Lab-grown diamond:** growing interest; needs clear certification and
  honest "lab-grown" labelling [verify disclosure rules].

### 1b. Choose test countries

Compare candidate countries on: demand for the category, ease of shipping
from our base, import duty on jewellery [verify], payment methods customers
expect, and language. Pick **1–2**.

### 1c. Find a niche

"Jewellery" is too broad to win online. Examples of angles to test:
minimalist everyday pieces, personalised/name jewellery, Indian ethnic
designs for the diaspora, men's jewellery, gifting, sustainable/recycled
metals. Validate with:
- Google Trends and marketplace search volume
- 5–10 competitor profiles (`notes/competitors/`)
- 10+ short conversations with target buyers (`notes/customers/`)

## Phase 2 – Business & legal setup

Depends on **the country where the business is registered**, not where
customers are. Tell us which country that is so these can be made specific.

- [ ] Register the business (sole proprietor vs company) [verify locally]
- [ ] Tax registration (e.g. GST/VAT) and export registration if required [verify]
- [ ] Business bank account; check it supports foreign-currency receipts
- [ ] Payment gateway that supports international cards (e.g. Stripe, PayPal,
      Shopify Payments, Razorpay — availability depends on registration country) [verify]
- [ ] Hallmarking / certification rules for the chosen metal in the test countries [verify]
- [ ] Policies: privacy, terms, shipping, returns/refunds (EU/UK customers
      have statutory cancellation rights for online purchases [verify])
- [ ] Trademark search for the brand name in home and test countries

## Phase 3 – Sourcing & samples

- [ ] Shortlist 3–5 suppliers (manufacturers, wholesale markets, print-on-demand
      jewellery, or own production)
- [ ] Order samples; check finish, plating durability, packaging, consistency
- [ ] Get certificates where relevant (purity, diamond grading, nickel-free)
- [ ] Build a **unit cost sheet** in `data/`: product + packaging + shipping +
      payment fee + duty/tax + returns allowance + marketing per order
- [ ] Rule of thumb to test: retail price ≥ 3× landed cost for fashion/silver
      to leave room for ads [verify against competitors]

---

## Phase 4 – Brand & store build

**Recommended platform: Shopify** for a worldwide store — multi-currency,
multi-language, international shipping and many jewellery themes, with no
coding needed to start. Alternatives: WooCommerce (cheaper hosting, more
maintenance), marketplaces like Etsy/Amazon (instant traffic, high fees,
less brand control). Many brands do both: own store + one marketplace.

- [ ] Brand name, domain, logo, colours
- [ ] Product photography — the single biggest factor for jewellery online
      (white-background + on-model + scale shots + video)
- [ ] Product pages: material, size in mm, weight, care, certificates
- [ ] Shipping zones and rates for test countries; decide who pays duties
      (DDP = we pay, smoother for customer; DDU = customer pays on delivery)
- [ ] Payment methods + currency display for test countries
- [ ] Trust: reviews, clear returns policy, secure checkout, contact details
- [ ] Analytics: Google Analytics, Meta pixel, Search Console

---

## Phase 5 – Soft launch

- [ ] Place test orders end-to-end to each test country
- [ ] Launch to friends, family and social followers first
- [ ] Instagram + Pinterest content (jewellery is highly visual)
- [ ] Small paid ad test with a fixed budget; track cost per sale
- [ ] Collect reviews and photos from first buyers

## Phase 6 – Grow

- Email/SMS list and flows (welcome, abandoned cart, post-purchase)
- SEO content (gift guides, care guides, size guides)
- Influencer / UGC partnerships
- Add countries one by one once the first ones are profitable
- Expand the range based on best sellers
